# Spotify Clone

A pixel-accurate Spotify Web Player UI clone built with pure HTML and CSS. Updated to match the latest Spotify UI (2026). Strictly frontend — no playable music, no backend.

## Features
- Fixed navbar with centered search bar
- Sidebar library panel
- Main content board with song cards and hover effects
- Collapsible queue panel
- Full music player UI with progress bar and volume control

## Tech Stack
- HTML5
- CSS3
- Bootstrap 5
- Remix Icons
- Font Awesome

## Note
This is a UI clone only. No audio playback, no Spotify API, no backend. Built purely for frontend practice.

## How to run
Open `index.html` in any browser. No setup or installation needed.
